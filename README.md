# MindTrack — Student Mental Wellness System

MindTrack is a team-developed Student Mental Wellness System designed to support students, educators, and administrators with a future-ready web platform and supporting AI capabilities.

## Project Structure

- frontend/ — React + TypeScript frontend workspace
- backend/ — Node.js + TypeScript + Express backend workspace
- ai/ — Independent Python AI/ML workspace
- docs/ — Architecture and project documentation
- infrastructure/ — Deployment and infrastructure configuration files
- scripts/ — Project automation scripts

## Planned Stack

### Frontend
- React + TypeScript + Vite

### Backend
- Node.js + TypeScript + Express.js
- PostgreSQL
- Prisma

### AI
- Python-based AI/ML workspace; exact models and frameworks will be selected later

## Development Status

Repository foundation only.

Application functionality has not been implemented yet.
